# Contributing to Awesome Claude Code Agent Skills

Thanks for helping keep this list useful. This is a simple list: one line per skill, grouped by the job the skill does.

## Adding a skill

1. Check the skill is not already on the list.
2. Open the skill repository and confirm the link loads and the skill is real and available.
3. Add one line to the right table in README.md in this format: `| [Name](URL) | What it does |`
4. Keep the description to one short line that says what the skill does.
5. Update the Entries badge and the Contents counts if your change alters them.
6. Use hyphen - instead of em dash everywhere.

## Rules

- The entry must be an Agent Skill, a skill pack, or a skill-based plugin for Claude Code or another AI coding agent.
- Link to the official repository or official skill page, not to a copy or mirror.
- One entry per skill. No duplicates.
- No trial-only or paid-only skills with no free way to use them.
- Read the skill files before you suggest it. Skills can include scripts, so only suggest skills from sources you trust.

## Pull requests

- One skill per pull request keeps review fast.
- Use a clear title, for example: Add Graphify to Research, Memory and Writing.
